# KOLDIS 0.6 – Produktfluss

Kernidee:
1. Start: „Was möchtest du diese Woche essen?“
2. Einmal kurz einrichten: Vorlieben, Ziele, Budget, Markt.
3. „Meine Woche planen“ erzeugt eine passende Woche.
4. Nutzer bestätigt oder plant einzelne Gerichte neu.
5. Einkauf wird aus der bestätigten Woche erzeugt.
6. Profil enthält spätere Änderungen.

Design:
- mobile first
- dunkle, ruhige Oberfläche
- Lime-Akzent
- keine KI-Foodbilder
- wenige, klare Hauptaktionen
- Bottom-Navigation auf Mobilgeräten
